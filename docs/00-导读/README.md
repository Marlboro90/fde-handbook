## 一句话

> FDE 交付的不是软件，是不确定性的收敛。

## 五层熵

| 层 | 你在收敛什么 | 收敛不了的后果 |
| --- | --- | --- |
| 意图 | 客户真正被考核的成果 | demo 惊艳，业务方不认 |
| 边界 | 范围与承诺 | 第 6 周还在加功能 |
| 现实 | 数据与系统的真实状态 | 进场第三天发现关键表没主键 |
| 效果 | 「好用」的可测定义 | 验收会上吵准确率 |
| 留存 | 系统被使用、被接管 | 部署完成，日活个位数 |
