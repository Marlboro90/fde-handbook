# 第 4 章　边界、承诺与最小部署

意图清楚了，接下来是承诺。这一章解决一个很具体的问题：怎么让范围在六周之后还是你当初答应的那个范围。答案不是「管好客户」，是让每一次变更都付出可计价的东西。

> 本章收敛：**boundary** ｜ 节数：4 ｜ 交付物：拒绝清单（L2）、架构决策记录（L2）
