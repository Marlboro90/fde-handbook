# 第 2 章　岗位坐标与读者定位

把「FDE 是什么」从职责描述换成两个坐标。职责描述说服不了面试官，也说服不了自己；坐标可以。读完你应该能在图上指出自己现在站哪、目标在哪、中间差的是哪一段。
