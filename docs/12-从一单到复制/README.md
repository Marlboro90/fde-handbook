# 第 12 章　从一单到复制

一次成功很容易变成不可复制的英雄故事。这一章说的是怎么把它变成判据、模板与失败模式清单——可复制的从来不是代码。

> 本章收敛：**retention** ｜ 节数：4 ｜ 交付物：复制判定表（L2）

## 本章小节

| 节 | 标题 | 一句话主张 | 判据级 |
| --- | --- | --- | --- |
| 12.1 | 可复制的是判据，不是代码 | 跨项目可复制的不是代码，而是「判据 + 模板 + 反模式清单」这三样东西。 | L2 |
| 12.2 | 该不该产品化看差异在哪一层 | 判断该不该产品化，看的是客户侧差异是否集中在配置层。 | L2 |
| 12.3 | 回流的是失败模式，不是需求 | 向产品团队回流的不是需求清单，是「在几个客户身上重复出现的失败模式」。 | L1 |
| 12.4 | 规模化的瓶颈是验收口径 | 规模化的真正瓶颈通常不是技术能力，而是验收口径无法标准化。 | L2 |
