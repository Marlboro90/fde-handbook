# 第 1 章　交付的本质是熵减

全书的地基。这一章不教方法，只给一副眼镜：让你在看一个失败项目时，能指出它是**哪一层**不确定性没有被收敛，而不是笼统地说「需求没想清楚」或「技术没选对」。五熵模型从这里开始，后面每一章都在收敛其中一层。
