# 第 9 章　评测即验收

全书技术制高点。评测在这里不是 RAG 章节里的一个小节，而是**验收合同的技术载体**：先建考题、再建系统，用双阈值放行，最后交一份能被反驳的报告。

> 本章收敛：**effect** ｜ 节数：4 ｜ 交付物：评测集与验收报告（L2）

## 本章小节

| 节 | 标题 | 一句话主张 | 判据级 |
| --- | --- | --- | --- |
| 9.1 | 先建考题，再建系统 | 评测集是需求的可执行版本；没有考题的需求在验收时一定会变成争议。 | L2 |
| 9.2 | 考题质量取决于难例与拒答占比 | 考题集的质量取决于难例与拒答样本的占比，而非题目总数。 | L1 |
| 9.3 | 单一分数不能支撑放行 | 必须双阈值：放行线与回滚线，单一分数不足以支撑放行。 | L2 |
| 9.4 | 验收报告要能被反驳 | 验收报告的功能是让不参与项目的人签字，因此它必须可被反驳。 | L2 |
