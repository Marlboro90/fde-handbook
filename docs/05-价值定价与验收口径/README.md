# 第 5 章　价值、定价与验收口径

技术判断要能被拿进会议室。这一章教你用客户自己的数字搭 ROI、用四种计价方式反推技术方案、把「差不多就行」翻译成可签字条款。全部动作只有一个原则：不编数字。

> 本章收敛：**effect** ｜ 节数：4 ｜ 交付物：ROI 结构表（L2）、验收条款（L2）
