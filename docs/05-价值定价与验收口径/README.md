# 第 5 章　价值、定价与验收口径

技术判断要能被拿进会议室。这一章教你用客户自己的数字搭 ROI、用四种计价方式反推技术方案、把「差不多就行」翻译成可签字条款。全部动作只有一个原则：不编数字。

> 本章收敛：**effect** ｜ 节数：4 ｜ 交付物：ROI 结构表（L2）、验收条款（L2）

## 本章小节

| 节 | 标题 | 一句话主张 | 判据级 |
| --- | --- | --- | --- |
| 5.1 | ROI 只能由客户的数字构成 | FDE 自己算的 ROI 是负债，不是资产；可信的做法是只给结构，数字向客户要。 | L2 |
| 5.2 | 计价方式决定技术方案 | 按结果计价时，评测与人工接管不是成本，是产品的一部分。 | L1 |
| 5.3 | 「差不多就行」是未翻译的验收标准 | 把模糊标准翻译成可测条款是 FDE 的合同义务，不是客户的刁难。 | L2 |
| 5.4 | 披露风险换的是信任额度 | 主动披露失败模式换的是信任额度，而非免责；隐瞒会在第一次误报时一次性偿付。 | L1 |
