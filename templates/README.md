# 交付物模板

六大交付物模板。**模板的价值在字段，不在格式**——字段缺失的模板只是装饰。

| 模板 | 对应章节 | 判据级 | 目录 |
| --- | --- | --- | --- |
| 成果契约 | 3.3 | L2 | `成果契约.md` |
| 拒绝清单 | 4.1 | L2 | `拒绝清单.md` |
| 架构决策记录 | 4.4 | L2 | `ADR.md` ✅ 已填字段 |
| ROI 结构表 | 5.1 | L2 | `ROI结构表.md` |
| 验收条款 | 5.3 | L2 | `验收条款.md` |
| 勘察记录 | 6.4 | L1 | `勘察记录.md` |
| 评测集 | 9.1 | L2 | `评测集.md` |
| Go-Live 清单 | 10.4 | L2 | `GoLive清单.md` |
| 交接手册 | 11.3 | L3 | `交接手册.md` |

> 状态：`ADR.md` 已填好实际字段（五段 + 十分钟检验表）。其余模板在对应章节定稿后补齐——**先登记清单、后填字段**，空模板比没有模板更容易误导。

## 使用约定

1. 复制到你的项目仓库，不要在这里改；
2. 字段可以按项目裁剪，但被删掉的字段要在文件头注明原因；
3. 模板的字段与判据卡一一对应，改字段需同步改对应章节的判据卡。
